PWA wrapper pro NHL Goal Analyzer

1. V index.html nahraď https://ca6t2x8drofn57qt6tcmgs.streamlit.app/ přesnou URL tvé Streamlit aplikace.
2. Nahraj index.html, manifest.json a icon.svg na web, který podporuje HTTPS (např. GitHub Pages).
3. Otevři tuto stránku v Safari na iPhonu → Sdílet → Přidat na plochu.

Pozn.: samotný Streamlit zůstává backendem; wrapper pouze dává aplikaci instalovatelný vzhled. Offline režim není podporován.
